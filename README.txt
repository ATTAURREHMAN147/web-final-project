NEXORA - 10 PAGE FRONTEND PROJECT

Technologies:
- HTML
- CSS
- Tailwind CSS (CDN)

Pages:
1. index.html - Home
2. about.html - About
3. services.html - Services
4. portfolio.html - Portfolio
5. pricing.html - Pricing
6. blog.html - Blog
7. testimonials.html - Testimonials
8. faq.html - FAQ
9. contact.html - Contact
10. 404.html - 404 Page

HOW TO RUN:
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open index.html.
4. Right-click index.html and choose "Open with Live Server" if you have Live Server installed.
5. Otherwise double-click index.html to open it in a browser.

Note:
Tailwind CSS is loaded through its CDN, so internet should be available when you run the project.
