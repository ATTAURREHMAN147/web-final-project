# QueueLess PK — 10 Page Frontend Project

## Idea
QueueLess PK is an academic frontend concept for reducing unnecessary waiting at participating government offices. A citizen selects an office/service, books a token (Rs.10 is used as an example), receives a time slot and visits around that time.

## Pages
1. Home
2. Offices
3. How It Works
4. Services
5. Book Token
6. My Token
7. About
8. FAQ
9. Contact
10. 404

## Technologies
HTML5, CSS3 and Tailwind CSS via CDN. No JavaScript is required.

## Run
Open `index.html` in a browser or use VS Code Live Server. Internet is needed for Tailwind CDN styling.

This is an academic frontend demo. It does not process real payments or connect to government systems.
